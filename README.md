# spokesavvy.net

The public pages for Spoke Savvy, served by GitHub Pages at https://spokesavvy.net:
`/` and `/support/`. The privacy policy is published at `/privacy/` (text from the app repo's
`docs/legal/privacy-policy.md`, #429) and the terms of use at `/terms/` (from
`docs/legal/terms-of-use.md`, PR #516). Re-render either with `tools/render_policy.py`. Static HTML only; nothing here is secret.
